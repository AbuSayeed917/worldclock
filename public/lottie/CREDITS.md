downloaded, and no third-party asset licence applies to this repository.

## Why these are generated rather than downloaded

The obvious source for Lottie animations is LottieFiles, but two problems ruled
it out for a public repository:

1. **Per-file licensing.** Free LottieFiles animations carry individual creator
   licences with attribution requirements that vary file by file. Verifying each
   one is a manual step that has to be repeated every time an animation changes.
2. **Verification.** The catalogue is not reachable programmatically, so files
   would have to be committed without confirming what they contain or whether
   they render.

Generating them removes both problems and makes the animations match the site's
palette exactly.

## Swapping in your own

The loader takes a path, so replacing any of these is a one-line change — set a
different `src` in [`src/ui/rail.ts`](../../src/ui/rail.ts) or the `HERO_SCENES`
map in [`src/main.ts`](../../src/main.ts), and drop your `.json` in this folder.

Two things to check on anything you download:

- **No external image references.** If the file has entries in `assets[]` with a
  `p` property, it depends on PNGs that will not be there, and it renders as an
  empty box. `scripts/build-lottie.mjs` has a `validate()` function that checks
  this and a few other invariants.
- **Every layer needs an `op`.** A layer with no out-point is never active, so
  the animation loads without any error and draws nothing at all — the quietest
  failure mode in this format, and one this project hit during development.

Record the source and licence of anything you add here.
